# formal-verification

Experiments with languages and tools that let a machine **check** that code
does what it claims, instead of trusting tests or an LLM's word.

| Folder | What | Status |
| --- | --- | --- |
| [`bend/`](./bend/) | A tiny verified, parallel tree library in [Bend](https://bend-lang.com/) — laws, proofs, and a native build | working demo |
